# PLAN — Phase 5: 영상 소스 생성기 (내부용 재료 도구)

> Created: 2026-07-31
> Phase: 5
> Requirements: R14, R15, R16, R17, R18
> Dependencies: Phase 4 완료 후

---

## Goal

두 번째 도구(영상 소스 생성기)가 탭으로 전환 가능하고, 씬 파싱, EN 프롬프트 생성, 상세도 조절, 카피 버튼이 동작함

---

## 이 도구의 성격

사용자 본인만 보는 내부용 재료 도구. 클라이언트에게 보여줄 목적이 아님. UI 완성도나 클라이언트향 설명에 시간을 쓸 필요 없이, 이미지/영상 생성 AI에 바로 넣을 수 있는 텍스트만 정확하게 뽑아내면 충분.

---

## Success Criteria

- [ ] "영상 소스 생성기" 탭 클릭 시 두 번째 도구로 전환
- [ ] 60초 대본 입력 → 씬 단위 자동 파싱 (최소 3개, 최대 10개 씬)
- [ ] 각 씬별 EN 이미지 프롬프트 + 모션 프롬프트 + 공통 스타일 접미사
- [ ] 상세도 조절 (최소/보통/상세) 선택 시 프롬프트 길이 변경
- [ ] 각 프롬프트에 카피 버튼 + "전체 복사" 버튼

---

## Waves

### Wave 1: 씬 파싱 + 프롬프트 생성 로직

**Plan文件:** `01-scene-parser.PLAN.md`

**Tasks:**
1. `template-video.js` — 씬 단위 파싱 + EN 프롬프트 생성
   - 60초 대본 텍스트 입력 → 씬 분리 (타임라인 기반)
   - 각 씬별 EN 이미지 프롬프트 생성
   - 각 씬별 모션 프롬프트 생성
   - 공통 스타일 접미사 자동 부착
   - 상세도별 프롬프트 길이 제어 (최소/보통/상세)

2. `video-ui.js` — 영상 소스 생성기 UI
   - 대본 입력 영역
   - 상세도 선택 (최소/보통/상세)
   - 생성 버튼
   - 결과 표시 영역 (씬별 프롬프트 카드)
   - 카피 버튼 + 전체 복사 버튼

**Dependencies:** None (first wave)

---

### Wave 2: 탭 전환 + 카피 버튼 통합

**Plan文件:** `02-tab-integration.PLAN.md`

**Tasks:**
1. `app.js` 업데이트 — 탭 전환 로직
   - "전략 제안서 생성기" / "영상 소스 생성기" 탭 전환
   - 탭 전환 시 기존 입력/결과 유지

2. `index.html` 업데이트 — 탭 UI
   - 탭 네비게이션
   - 영상 소스 생성기 컨테이너

3. `style.css` 업데이트 — 탭 + 영상 소스 UI 스타일

**Dependencies:** Wave 1 완료 후

## Risk Mitigation

|------|------------|
