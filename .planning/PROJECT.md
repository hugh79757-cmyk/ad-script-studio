# PROJECT — AD SCRIPT STUDIO (이커머스 전략 제안서 생성기)

## Vision

이커머스 마케터/MD가 입력한 브랜드·상품·타겟·리뷰 정보를 기반으로 **"감이 아니라 논리로 만든" 전략 제안서**를 자동 생성하는 웹 기반 도구. 광고 대본은 그 제안서 안에 포함된 하나의 구성요소이며, 핵심 가치는 **제품별 맞춤 당위성 근거**와 **설득형 제안서 문서화**에 있다.

두 가지 핵심 도구:
1. **전략 제안서 생성기 (Strategic Proposal Generator)** — 문제 진단 + 전략 근거 + 광고 대본 + 스토리보드 + 기대효과를 포함한 클라이언트향 제안서 생성
2. **영상 소스 생성기 (Video Source Generator)** — 내부용 재료 도구. 대본을 씬 단위로 파싱하여 이미지/영상 생성 AI에 바로 쓸 수 있는 EN 프롬프트 생성

## Goals

### Validated (이전 세션 완료)
- `skills/custom/shortform-copywriting.md` 추출 완료 — 26개 원칙 (단축 규칙 10, 공식템플릿 5, 해외캠페인 11)
- `skills/marketing/` 디렉토리에 13개 마케팅 스킬 원본 보유

### Active (이 마일스톤)
- [ ] P1: 전략 제안서 생성기 UI 골격 — 2패널 레이아웃, 다크테마, **10개 입력 필드**, 결과 영역 (바닐라 JS)
- [ ] P2: 기획안 생성 로직 + 결과 렌더링 + PDF — 템플릿 기반 대본 생성(제안서의 구성요소로), jsPDF, 복사/새로 만들기
- [ ] P3: **당위성 엔진 + 설득형 제안서 문서화** ⭐ — 제품별 맞춤 근거 생성, 문제진단→전략→크리에이티브→기대효과→원칙부록 순서 제안서 PDF
- [ ] P4: Claude API 자동화 — 서버사이드 API 연동, 자동 모드에서 당위성 엔진 진가 발휘
- [ ] P5: 영상 소스 생성기 — 내부용 재료 도구, 씬 파싱, EN 프롬프트, 상세도 조절, 카피 버튼 (UI 간소화)
- [ ] P6: 두 도구 연결 + 배포 — 탭 전환, "2번으로 보내기" 자동 전달, Vercel 배포, 통합 E2E 테스트

## Success Criteria

| 기준 | 측정 방법 |
|------|----------|
| 전략 제안서 생성기가 제품별 맞춤 당위성 근거를 생성할 수 있다 | "왜 이 원칙이 필요한가" 근거 문장이 입력값 기반으로 표시됨 |
| 제안서 PDF가 설득 논리의 흐름을 따른다 | 문제진단→전략및근고→크리에이티브→기대효과→원칙부록 순서로 렌더링 |
| 수동 모드에서 정형 근거가 표시된다 | 당위성 근거 카드에 원칙명 + 간단 근거 표시 |
| 자동 모드에서 논리적 근거가 생성된다 | Claude API 연동 시 입력값과 원칙을 연결한 논리적 서술 표시 |
| 영상 소스 생성기가 씬별 EN 프롬프트를 정확히 생성한다 | EN 프롬프트 카피 버튼으로 복사 가능 |
| 두 도구가 연결되어 기획안 → 영상 소스로 자동 전달된다 | "2번으로 보내기" 버튼 클릭 시 자동 전달 |
| Vercel에 배포되어 접근 가능하다 | 배포 URL로 접속하여 전체 플로우 동작 확인 |

## Scope

### In Scope
- 전략 제안서 생성기 (Strategic Proposal Generator)
- **당위성 엔진** — 제품별 맞춤 근거 생성 (수동 정형 문구 + 자동 API 논리)
- **설득형 제안서 PDF** — 문제진단→전략및근거→크리에이티브→기대효과→원칙부록
- 영상 소스 생성기 (내부용 재료 도구)
- 두 도구 간 탭 전환 및 자동 전달
- 스킬 지침 (26원칙) 시스템 프롬프트 주입
- 클라이언트 제안용 PDF 다운로드 (일반PDF + 제안서PDF)
- Vercel 배포 (서버리스 함수 포함)
- 수동 복붙 모드 → API 자동화 모드 점진적 전환

### Out of Scope
- 영상 편집 도구 연동
- 사용자 인증/로그인
- 결제 시스템
- 데이터베이스 저장 (클라이언트 사이드)
- 모바일 네이티브 앱

## Constraints

- **프론트엔드**: 바닐라 HTML/CSS/JS (React, Next.js 등 프레임워크 사용 안 함)
- **API 키 보안**: Anthropic API 키는 서버 사이드(Vercel 서버리스)에서만 처리, 프론트엔드에 노출 금지
- **배포**: Vercel (serverless functions + static hosting)
- **언어**: 대본 생성은 한국어, 영상 소스 프롬프트는 영어 (EN)
- **스킬 소스**: `skills/custom/shortform-copywriting.md` (26개 원칙) — 런타임에 서버리스 함수가 읽어 시스템 프롬프트에 주입
