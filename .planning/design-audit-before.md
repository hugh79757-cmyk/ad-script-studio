## 결함 목록 (generate_carousel.py / generate_carousel.js 코드 분석 기반)

### 1. 시각적 계층 없음
- 모든 슬라이드가 동일한 중앙정렬 구조
- 제목(64px) → 부제목(36px) → 본문(32px)의 3단계일 뿐, 실제 정보 설계 없음
- 슬라이드 내에서 중요도별 시각적 무게감이 전혀 구분되지 않음

### 2. 브랜드 컬러 없음
- 모든 캠페인이 동일한 색상 사용:
  - 표지: dark navy (#0D1B2A)
  - 콘텐츠: light gray (#F8FAFC)
  - CTA: blue (#1E40AF)
- 식품(웜톤), 뷰티(파스텔+블루), 전자기기(다크+네온)에 맞는 컬러 팔레트 부재
- 브랜드 아이덴티티를 전혀 드러내지 못함

### 3. 여백/그리드 없음
- 상하좌우 여백 고려 없이 중앙정렬만 사용
- 카드/섹션 단위 구획 없이 텍스트가 화면에 흩뿌려진 느낌
- 그리드 시스템이 없어 요소들이 무작위로 배치된 인상

### 4. 제품 이미지 미사용
- Pixabay/Pollinations 등에서 생성된 제품 이미지가 존재함에도
  슬라이드에 전혀 삽입되지 않음
- 표지에도 제품 이미지가 없고 텍스트만 있음

### 5. 아이콘/이모지 처리 미흡
- 👉 같은 기본 이모지만 사용
- SVG 아이콘 사용하지 않음 → 렌더링 환경에 따라 깨질 위험
- 시스템 폰트 의존으로 이모지 렌더링이 플랫폼마다 다를 수 있음

### 6. 단조로운 레이아웃
- 6장 모두 "제목 + 구분선 + 본문" 동일 구조
- 슬라이드 유형별(표지/전략/타겟/메시지/CTA) 레이아웃 차별화 없음
- 카드, 인용구, 비교표, 체크리스트 등 실제 UI 컴포넌트 요소 전무

### 7. 슬라이드 간 시각적 일관성 부족
- 타입별로 배경색만 다를 뿐 디자인 언어가 통일되지 않음
- 표지→콘텐츠→CTA로 이어질 때 스토리텔링 흐름의 시각적 연속성 없음
- 페이지 번호 디자인도 단순 텍스트

### 8. 쇼츠 영상(render_video.py) 문제
- 정적 이미지에Ken Burns 효과 없음 (완전 고정 이미지)
- 자막: 단순 반투명 검정 배경 + 흰색 텍스트, 외곽선/그림자 없음
- 자막 위치가 쇼츠 UI 안전영역(하단 버튼 영역)을 고려하지 않음
- 씬 전환: 단순 컷, 페이드/줌 전환 없음
- 배경음악 없음

## 기술 스택 문제점
- Pillow 기반 직접 렌더링 → 복잡한 레이아웃/그라디언트/그림자 표현 어려움
- 한글 폰트: 시스템 폰트 감지에 의존, 웹폰트 사용 안 함
- node-canvas도 동일한 한계 (Pillow보다는 낫지만 여전히 코드 기반 드로잉)
- 이모지 SVG 대신 유니코드 사용으로 환경 의존적

## 결론
현재 결과물은 "텍스트를 배경에 중앙에 배치한 수준"으로,
실제 마케팅 에이전시가 제작한 인스타그램 캐러셀/유튜브 쇼츠와 비교하면
퀄리티 차이가 큼. HTML/CSS 템플릿 + 헤드리스 브라우저 렌더링 방식으로
전환하고 본격적인 디자인 시스템을 적용해야 함.
