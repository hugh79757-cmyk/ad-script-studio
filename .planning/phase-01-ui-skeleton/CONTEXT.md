# CONTEXT — Phase 1: 전략 제안서 생성기 UI 골격 + 입력 필드 확장

## Goal
2패널 레이아웃, 다크테마, **확장된 10개 입력 필드**가 동작하는 클라이언트 사이드 UI 골격 완성

## Requirements
R1, R2, R3, R4, R23, R24

## User Specification (의뢰자 상세 사항)

### 입력 필드 10개

**기존 5개:**
1. 브랜드명 (text, 필수)
2. 제품명 (text, 필수)
3. 컨셉 (textarea)
4. 타겟 (text, 필수)
5. 톤앤매너 (select: 진지/유쾌/감성/유머/시크/발랄/몽환/강렬)

**신규 5개:**
6. 경쟁사명 (text) — "경쟁 제품명과 우리 제품의 차별점"
7. 가격대 (text) — "예: 39,000원, 첫 구매 시 할인顾虑"
8. 리뷰 발췌 (textarea, 여러 줄) — 줄바꿈으로 구분하여 **배열로 저장**
9. 브랜드 신뢰요소 (태그 입력창) — "수상내역, 판매량, 인증 등" **여러 개 입력 가능한 태그**
10. 제외키워드 (태그 입력창, 쉼표 구분) — "이 광고에서 사용하지 않을 키워드"

### state-manager.js 통합

각 필드의 값은 `state-manager.js`의 전역 state 객체에 저장:
```javascript
const state = {
  brandName: '',        // 브랜드명
  productName: '',      // 제품명
  concept: '',          // 컨셉
  target: '',           // 타겟
  toneAndManner: '',    // 톤앤매너
  competitorInfo: '',   // 경쟁사명/차이점
  priceRange: '',       // 가격대
  reviewExcerpts: [],   // 리뷰 발췌 (배열) ← 줄바꿈으로 구분
  trustFactors: [],     // 브랜드 신뢰요소 (배열) ← 태그 입력
  excludedKeywords: []  // 제외키워드 (배열) ← 쉼표 구분
};
```

**특히 중요:**
- 리뷰 발췌와 신뢰요소는 **배열 형태**로 저장 → Phase 3에서 각 항목을 개별적으로 참조할 수 있어야 함
- 리뷰 발췌: textarea에서 줄바꿈(\n)으로 구분하여 배열 변환
- 신뢰요소: 태그 입력 UI (쉼표 또는 Enter로 추가)
- 제외키워드: 쉼표 구분 입력 → 배열 변환

### 필드별 "왜 이 정보가 필요한지" 설명

각 필드 옆에 placeholder 텍스트 또는 툴팁으로 간단한 설명:
- 브랜드명: "광고 주체 브랜드명을 입력하세요"
- 제품명: "광고할 제품/서비스 이름을 입력하세요"
- 컨셉: "제품의 핵심 컨셉이나 메시지를 입력하세요"
- 타겟: "타겟 고객층을 입력하세요 (예: 25~35세 여성, 직장인)"
- 톤앤매너: "광고의 분위기를 선택하세요"
- 경쟁사명: "경쟁 제품과의 차별점을 입력하면 더 설득력 있는 전략이 나옵니다"
- 가격대: "가격 정보가 있으면 구매 장벽 분석에 활용됩니다"
- 리뷰 발췌: "실제 고객이 쓴 표현을 그대로 넣으면 더 설득력 있는 카피가 나옵니다"
- 브랜드 신뢰요소: "수상내역, 판매량, 인증 등 신뢰 요소를 입력하세요"
- 제외키워드: "이 광고에서 사용하지 않을 키워드를 입력하세요"

## Architecture Decisions

- **프레임워크:** 바닐라 HTML/CSS/JS (React, Next.js 등 사용 안 함)
- **단일 HTML:** `index.html` + `style.css` + `app.js` + `state-manager.js`
- **CSS 변수로 테마 관리:** `:root`에 `--bg-primary`, `--text-primary` 등
- **반응형:** `@media (max-width: 768px)` 기준 2패널 → 1패널 스택

## Scope

### In Scope
- 2패널 레이아웃 (좌: 10개 입력 필드, 우: 결과 영역)
- 다크테마 (배경 #0a0a0a~#1a1a1a, 텍스트 #e0e0e0 이상)
- 10개 입력 필드 (기존 5 + 신규 5)
- 상태 관리 (`state-manager.js`)
- 반응형 레이아웃
- 필수 필드 검증 (브랜드명, 제품명, 타겟)

### Out of Scope
- 대본 생성 로직 (Phase 2)
- PDF 생성 (Phase 2)
- API 연동 (Phase 4)
- 영상 소스 생성기 (Phase 5)
- 결과 영역의 실제 데이터 렌더링 (Phase 2~3)

## Constraints
- 바닐라 JS only — 프레임워크 사용 금지
- CSS 변수로 테마 관리
- 단일 HTML 파일 구조
- 브라우저에서 바로 동작해야 함 (빌드 스텝 없음)
