## 0. 이 자료를 쓰는 순서 (한 줄 요약)

가입 → **공식 이용 가이드 필독** → 황금 키워드 선정 → 상품/고유링크 발급 → 제목(상품명 답지) → 모바일 친화 정보성 글(사진 8~10장, 단점 포함, 최종 체감가 명시) → 썸네일은 실사용 리뷰 사진 → 상단+하단 링크 2개 → 발행 → 저품질 방지(검색형+쇼핑형 섞기).

## 1. 브랜드커넥트 / 쇼핑커넥트란?

### 1.1 정의
- **쇼핑커넥트 = 네이버의 퍼포먼스(제휴) 마케팅**. 쿠팡 파트너스가 쿠팡 전용이라면, 네이버는 후발주자로 같은 구조를 만들었다(`19:30`).
- "브랜드커넥트"는 쇼핑커넥트와 같은 크리에이터 수익화 생태계의 한 축(여행/브랜드 등 카테고리 확장). 강의는 쇼핑커넥트 중심이나 원리는 동일(`02:36`, `36:35`).

### 1.2 구조 (4단계)
1. 스마트스토어 판매자가 상품 등록 + **수수료율 설정**(5%~48%)
2. 크리에이터가 상품 선택 → **고유 링크 발급**(필수)
3. 컨텐츠(블로그 등) 생산 + 링크 삽입
4. 구매자가 링크 클릭 → **구매 확정** → 네이버 경유 수수료 정산(`20:03`~`21:54`)

> ⚠️ **"고유 링크"는 상품 페이지 URL이 아니다.** 내가 팔아야 수수료를 인정받는 **나 전용 링크**. 링크 안 발급하면 시스템적으로 실적이 절대 안 남는다(`20:55`).

### 1.3 쿠팡 파트너스와 다른 점
| 구분 | 쇼핑커넥트 | 쿠팡 파트너스 |
|---|---|---|
| 네이버 블로그 노출 | 공식이라 안정적 | **일주일도 못 버티고 저품질**(`55:05`) |
| 수수료율 | 판매자가 5~48% 설정 | 고정 |
| 경쟁 강도 | 후발주자라 낮음 | 빡셈(`57:15`) |
| 직접 실적 유리도 | 유리(`54:02`) | — |

→ **결론: 네이버 블로그로 돈 벌 거면 쿠팡 파트너스 링크는 올리지 말 것.** 저품질 직행(`45:12`, `55:05`).

## 2. 가입 / 온보딩 (승인 불필요)

- **가입만 하면 바로 시작**. 애드포스트/애드센스처럼 승인 절차 없음(`49:46`). 미루지 말 것.
- 경로: `쇼핑커넥트` 검색 → `크리에이터` → **`이용 가이드`(공식) 필독**(`30:48`~`34:00`).
- **이용 가이드에 반드시 나오는 것**:
  - 통합 이용 가이드
  - 실적 인정 기준
  - 정산/매출 증빙
  - 채널별 링크 삽입 방법
  - **활동 제한 채널 리스트** (`32:54`~`34:00`)
- 가이드에는 *"어떻게 링크를 달아야 공정거래위원회(공정위)에 위반되지 않는지"*가 전부 명시돼 있음 → **꼭 직접 읽을 것**(`32:44`).

## 3. 수익 구조 / 정산

### 3.1 수수료 모델
- **직접 실적**: 내 링크로 내가 홍보한 그 제품 구매 → 기본 **5%~최대 48%**. (예: 48% 상품 5만 원 → 25,000원, `54:30`)
- **간접 실적**: 내 링크로 유입돼 **다른 제품** 구매 → **1.8%**(`29:48`). 룰 복잡 → 가이드 참고.
- 일부 국내 제품(삼성/휴대폰)은 **3%**도 존재(`28:54`).
- 고가일수록 유리: 50만 원×5% = 25,000원 vs 5,000원×5% = 250원(`75:30`).

### 3.2 정산 / 보너스
- 구매 **확정** 이후 네이버 경유 입금(`21:26`).
- 네이버 수수료 보조 이벤트로 5%→7%(`57:26`).
- 실적 우수 시 **업체가 직접 연락해 수수료 인상** 제안(예: 삼성 본사 지원 5%→7%, `61:50`).
- 따라오는 보너스 5가지(`59:28`~`72:53`): ① 애드포스트 단가 상승 ② 업체 직접 수수료 인상 ③ 협찬/원고료 ④ 체험단 등급 상승(다이아면 100% 지원+원고료) ⑤ 업체 선물.

### 3.3 강사 실적 참고
- 누적 매출 약 15억, 월 최대 수익 930만 원(베타), 네이버 블로그 순수 수익 누적 약 1억(`10:18`~`11:18`).
- **쇼핑커넥트 유입 글은 애드포스트 단가가 일반 블로그 대비 2~4배** — 검색 의도가 뚜렷해 타겟 광고가 붙기 때문(`56:47`).

## 4. 네이버 블로그 글쓰기 실전 (핵심)

### 4.1 글의 본질
- "내가 쓰기 편한 글"이 아니라 **남이 끝까지 읽기 편한 글**(`122:51`).
- **모바일 작성 모드** 필수. PC 접속자 20~30%뿐, 모바일 깨지면 이탈→전환↓. 체류시간↑ = 전환율↑ = 알고리즘 긍정(`116:09`~`122:48`).

### 4.2 추천 포스트 구조 (4단계, `119:02`)
1. **초반에 혜택 제시** — 행사 기간, 쿠폰, 싸게 사는 법. 이탈 방지용.
2. **시각 구조** — 인용구 말풍선 박스 + 관련 이미지 매치.
3. **소제목 + 사진(상세페이지 캡처) + 본문** 3요소 일치.
4. **띄어쓰기 2~3줄 단위** — 모바일 스크롤 고려.

### 4.3 제목 만들기 = "제목은 답지"
- 판매자는 키워드 분석해 상품명을 지었음 → **그 상품명을 롱테일 키워드로 살려 쓰면 시간 대폭 단축**(`110:45`).
- **롱테일 키워드** = 브랜드+모델+스펙 조합.
  - 예: `"자렛 글라스 F 에어프라이어 4.5L vs 5.5L 비교 장점 단점 세척"`(`112:54`)
- **품번(모델번호) 검색 공략** (강력 추천, `139:40`): 가전/의류/신발은 생김새가 비슷해 품번으로 검색하는 수요 다수. 제목+본문에 품번 포함 → 경쟁 거의 없이 상위 노출. 예: `JMW M5001`, `spj09`, `나이키 hj20-101`.
- **단점은 반드시 쓸 것**(`96:38`): "너무 칭찬만 하면 광고 같음". 제목+본문에 구매 결정에 영향 안 갈 사소한 단점 1개 포함. 어그로만 끌고 본문에 없으면 "품질 안 좋은 글" 됨.

### 4.4 사회적 증거 세팅 (신뢰 구축)
- 브랜드 파워 / 누적 판매량 / 리뷰 수 / 평점(4.8~4.9)을 **상세페이지에서 캡처해 상단 배치**(`77:21`~`79:43`, `123:44`).
- "100마디보다 강력" — 굳이 글로 쓰지 말고 캡처 사용.

### 4.5 가격 세팅 (가장 중요, `126:10`)
- **"최종 체감가"를 무조건 명시** — 할인+정액 환급+포인트 적립 모두 적용한 실결제가.
- 사고 싶은 사람에게 **합리화 근거 하나 더 줌**.
- 정부 환급 / 삼성 감사제 20% 등 행사 겹칠 때 매출 부스팅(`130:21`).

### 4.6 사진 (8~10장)
- 제품 특장점 사진 4~5장 + 사회적 증거 캡처 → 총 8~10장(`154:13`).
- **실제 사진**이 노출/전환에 훨씬 긍정적. AI 생성 사진은 지양(§5 썸네일 참조).
- AI 글쓰기: 글자수 1,000~1,500자, 프롬프트로 소제목+관련이미지+본문 구조 생성(`155:34`).

### 4.7 검색 노출 / 키워드 전략
- **키워드가 유입의 95% 이상**(`91:48`). 조회수 적어도 포기하지 말 것 — 검색 유입자는 구매 의도 있어 전환 잘 됨.
- **황금(틈새) 키워드**: 월간 검색량 낮고 누적 발행량 적은 매출전환 키워드. 블로그 기준 **월 1,000 이하** 추천, 초보는 **470 정도**도 OK(`106:10`).
- **시즌성**: 여름=선풍기/에어컨, 가을=환절기/캠핑, 겨울=난방. 연예인 PPL 방송 직후 검색 폭증 → 당일 업로드(`132:36`).
- **신제품**: 키워드 최대한 쪼개기(색상/카메라/할인/개봉기), 실물 후기 사진(코스트코·트레이더스는 직원 방해 적음, `145:10`). 본품 경쟁 치열하면 **소모품(케이스/액정보호필름)**이 경쟁 적음(`147:53`).

### 4.8 링크 삽입 (가장 중요한 규정)
- **고유 링크만** 사용. 상품 페이지 URL 그대로 쓰면 실적 안 남(`20:55`).
- **개수**: 한 포스팅에 링크 도배 = **공식 홈페이지 제재 사유 등재**(`115:42`).
  - 강사 방식: **상단 1개 + 하단 1개** (같은 링크 2개, `162:30`).
  - 상단 배치 이유: "사람들 끝까지 안 읽는 경우 많아서 맨 마지막만 있으면 안 누르고 나감"(`162:38`).
- 채널별 삽입 규정은 공식 가이드 참고(채널마다 다름).

## 5. 썸네일 생성 주의사항 (상세)

> 강의는 네이버 **블로그 포스트 대표이미지** 위주(유튜브 썸네일 정책은 별도). 명시적 "썸네일 정책 위반" 규정은 적으나, 실전 CAUTION은 다음과 같음.

### 5.1 실사용 리뷰 사진 썸네일 권장 / AI 이미지 지양
- *"썸네일에 그냥 AI 돌리거나 상태찍은 거를 누르실래요, 아니면 실제 찍어 온 실사용 후기 사진을 누르실래요?"* → **실제 사진이 클릭 확률 훨씬 높음**(`146:15`).
- 클릭 관문은 썸네일. 실제 사진은 "실구매 리뷰 같은 느낌"을 줘 상단이 아니어도 클릭 유도(`156:41`).
- **강사는 AI 사진 안 씀.** 제품 사진 or 상세페이지 사진 사용. 실제 사진이 노출/전환에 "유미할 정도로" 긍정적(`155:04`).

### 5.2 저작권 CAUTION (중요)
- ✅ **상세페이지 사진은 100% 사용 가능** — "20억대 업체부터 삼성/LG까지 다 '써도 된다'고 했음. 쇼핑커넥트 등록 자체가 '많이 팔아라' 의미"(`51:51`~`53:14`).
- ❌ **개인 리뷰 사진 사용 = 저작권 침해(불법)** — "개인들이 찍은 사진 쓰는 사람 있는데 이건 사실 불법"(`53:20`).
- ⚠️ **인물(모델) 사진은 최대한 안 씀** — 모델 교체 시 애매(`53:36`). 제품 사진 위주 권장.
- 예외: 판매자가 "재판매 금지" 명시한 곳(쿠팡 맞춤 붙여 파는 자들 막으려는 용도)만 쓰지 말 것(`52:30`).

### 5.3 기타
- 블로그 대표이미지도 **모바일 가독성** 고려(§4.1 참조).
- 이미지 생성 AI 툴 시연 중 나온 "욕하지 말고 어르고 달래야 말 잘 들음" 등은 툴 사용 팁이지 정책 아님(`196:20`).

## 6. 광고법 / 심의 / 컴플라이언스 경고 (절대 주의)

### 6.1 공정위 위반 금지
- 가이드에 *"어떻게 링크를 달아야 공정위에 위반되지 않는지"* 명시(`32:44`). 불이행 시 제재/저품질 대상.
- **활동 제한 채널**(일베 등 논란 채널)에 올리면 수익화 불가 + 제재. 리스트는 수시 업데이트(8/11, 6/26 등) → 가끔 재확인(`34:00`~`35:13`).

### 6.2 건강기능식품 — 가장 많이 걸리는 위반 (`160:09`)
- "가장 많이 걸리는 경우는 건강기능식품 규칙 위반. **원료 효능이 아닌 제품 직접 효능을 이야기하면 위반**."
- 위반 시 **저품질(적품질) 제재**. 링크 도배와 함께 공식 홈페이지에 제재 사유 대시 표시.

### 6.3 "내돈내산" 표기 — 네이버가 싫어함 (중요, `169:21`)
- *"내돈내산은 쓰지 마세요. 내돈내산은 애드포스트로만 돈을 벌어야 해요. 쇼핑커넥트를 오히려 못 하게 막더라고요."*
- 내돈내산 표기한 쇼핑커넥트 글은 노출 방해. → **절대 쓰지 말 것.**

### 6.4 협찬/원고료 사기 주의 (`169:47`~`175:09`)
- "협찬 업체 거의 다 요즘 사기 많고 싼 거 줌. 무시하셔도 됨."
- 의심 메일: 가입 유도 / 개인정보 요구 / 선입금 요구 / 고수익 → "세상에 공짜 없음. 조회수 10~100 나오는데 10만 원 준다? 그런 건 존재 안 함 → 사기."
- 정식 체험단은 리뷰노트/레뷰/슈퍼멤버스 등 경쟁 치열한 곳.

### 6.5 경업 금지(직장인) — 세무사 상담 (`168:29`)
- 경업 금지 조항은 회사마다 다름 → 강의가 알려줄 수 없음. "회사에서 잘릴 수 있으니 세무사와 상담."
- 회사가 안 된다면 **가족 계좌**(배우자/부모/아이디) 사용 권유.

### 6.6 기타
- 세금: 개인 명의 3계정 가능, 종합소득세는 나중 취합 계산(`163:34`).
- 블로그 공개: "돈 못 벌 때는 공개하는 게 맞지만, 돈 벌기 시작하면 숨기는 게 좋음"(경쟁자 카피 방지, `168:15`).

## 10. 콘솔 운영 보충 (naver-brandconnect 스킬 기반)

실제 수익을 확인·링크 발급하려면 크리에이터 콘솔 진입 필요.

### 10.1 계정 전제
- **크리에이터 가입 + 채널 등록된 계정만 콘솔 진입 가능.**
- 예: `achaan1` = 활성 크리에이터(채널ID `856892307893216`). `twinssn@naver.com`은 미가입이라 콘솔 경로 전부 마케팅 랜딩/404 → 절대 시도 금지.

### 10.2 콘솔 URL (`{channelId}` = `856892307893216`)
| 용도 | URL |
|---|---|
| 상품 찾기 | `brandconnect.naver.com/856892307893216/affiliate/products` |
| 발급 링크 관리 | `.../affiliate/products-link` |
| 판매 실적 | `.../affiliate/sales-dashboard` |
| 정산 관리 | `.../settlement/affiliate` |

### 10.3 판매 실적 해석 함정 (중요)
- 대시보드는 **포스트(글) 단위 귀인을 제공하지 않음.** 귀인 단위는 '상품' + '링크 발급 여부'뿐 → "어느 글에서 판매 났는지"는 콘솔 단독으로 알 수 없음.
- **'링크 발급=완료'는 판매 유입 경로를 뜻하지 않음.** 단정 금지.
- 초기 로드 중 과도기값 주의(수 초 후 재읽어 확정).
- 글↔판매 매핑이 필요하면 발급 링크(naver.me)를 발행 글 본문과 교차대조(별도 크롤) — 그래도 "실제 판매로 이어졌는지"는 대시보드에 없음.

### 10.4 제휴 링크 발급/복사
- **발급 링크 포맷**: `https://naver.me/{productId}` (예: `G6R0dOt7` → `https://naver.me/G6R0dOt7`).
- 상품 찾기 → 해당 행 '링크 발급' 클릭으로 생성. '복사' 버튼으로 클립보드.
- 이 `naver.me` 링크를 §4.8 방식(상단+하단)으로 블로그 글에 삽입.
